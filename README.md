# DNS Resolution and Security Analysis

## About This Project
This project explores the Domain Name System (DNS), its resolution process, and network packet analysis using Wireshark.

It covers DNS fundamentals, record types, DNS query and response analysis, common DNS attacks, detection techniques, and mitigation strategies from a cybersecurity and SOC Analyst perspective.

## Topics Covered
- DNS Fundamentals and Architecture
- DNS Resolution Process
- Recursive and Iterative Queries
- DNS Record Types (A, AAAA, CNAME, MX, TXT, NS)
- DNS Caching and TTL
- DNS Packet Analysis Using Wireshark
- Common DNS Security Attacks
- DNS Attack Detection and Mitigation

## Tools Used
- Wireshark
- Windows Command Prompt
- Nslookup

## Project Files
- `DNS-Theory-and-Security.md` – DNS concepts, resolution process, attacks and mitigation.
- `Wireshark-Practical-Lab.md` – Hands-on DNS packet analysis and practical exercises.

## Learning Outcome
Developed practical knowledge of DNS communication, packet analysis, network security threats and SOC investigation techniques.

**Domain:** Networking & Cybersecurity
